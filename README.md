# PaisaWise 💰 — Savings Diary

A smart personal finance tracker — track daily expenses,
visualize monthly spending, and get saving tips.

## Tech Stack
- **Frontend** — React + Vite + Tailwind CSS
- **Backend** — Node.js + Express + PostgreSQL

## Local Setup

### Backend
cd paisawise-backend
npm install
npm run dev

### Frontend
cd paisawise
npm install
npm run dev
